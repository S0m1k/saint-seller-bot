# Saint Seller — Telegram-магазин

Telegram-бот с веб-приложением (каталогом) для магазина одежды
[@saint_seller812](https://t.me/saint_seller812).

Стек: **Python · aiogram 3 · FastAPI · SQLite (async)**. Бот и веб-приложение
работают в одном процессе — единый запуск через `run.py`.

## Возможности

**Бот / админка (`/admin`, доступ по Telegram ID из `ADMIN_IDS`):**
- CRUD товаров с пошаговым мастером: название, бренд, размер, категория,
  состояние, цена, описание, несколько фото.
- Категории: добавление / удаление.
- Управление товарами: список, скрыть / показать, удалить.
- Заказы: подтверждение / отмена / отметка «выполнен» с уведомлением покупателя.
- При добавлении товара — **рассылка всем пользователям** (кроме админов) с фото
  и кнопкой перехода в каталог; админу приходит только отчёт об успехе.

**Веб-приложение (Telegram Web App):**
- Каталог с разделением по категориям.
- Поиск по названию/бренду и фильтр по бренду.
- Избранное и корзина (привязаны к Telegram-аккаунту).
- Оформление заказа → уведомление админу; подтверждение — в админке.
- История заказов, профиль с телефоном.

## Структура

```
core/     — конфиг, БД, модели (SQLAlchemy)
bot/      — aiogram: хэндлеры, клавиатуры, FSM, рассылка
api/      — FastAPI: роутеры, auth по Telegram initData, схемы
webapp/   — веб-приложение (HTML/CSS/JS, без сборки)
media/    — фото товаров (создаётся автоматически, в git не попадает)
run.py    — запуск API + бота вместе
```

## Установка

```bash
python -m venv .venv
# Windows:  .venv\Scripts\activate
# Linux/mac: source .venv/bin/activate
pip install -r requirements.txt

cp .env.example .env   # и заполнить значения
python run.py
```

## Настройка `.env`

| Переменная    | Описание                                                        |
|---------------|-----------------------------------------------------------------|
| `BOT_TOKEN`   | Токен бота от [@BotFather](https://t.me/BotFather).             |
| `ADMIN_IDS`   | Telegram ID админов через запятую.                              |
| `WEBAPP_URL`  | Публичный **HTTPS**-адрес сервера (для кнопки Web App).         |
| `API_HOST/PORT` | Хост и порт сервера.                                          |
| `DATABASE_URL`| Строка подключения (по умолчанию SQLite).                      |
| `DEBUG`       | `true` — открывать каталог в браузере без Telegram (для теста). |

> **Секреты только в `.env`** — файл в `.gitignore` и в репозиторий не попадает.

## Развёртывание

Telegram Web App требует **HTTPS**. Варианты:
- поставить за reverse-proxy (nginx/Caddy) с TLS-сертификатом;
- для локального теста — туннель (ngrok/cloudflared) и указать его URL в `WEBAPP_URL`.

После запуска в @BotFather у бота автоматически ставится кнопка меню «Каталог».

## Как это работает

1. `run.py` создаёт таблицы и параллельно поднимает FastAPI (webapp + API на
   `/api`, фото на `/media`) и long-polling бота.
2. Веб-приложение при каждом запросе шлёт заголовок `X-Telegram-Init-Data`;
   сервер проверяет подпись Telegram и авторизует пользователя.
3. Заказы и уведомления о новых товарах идут через тот же экземпляр бота.
